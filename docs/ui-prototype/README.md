# Parameter Foundry UI Prototype

This is an interactive, implementation-independent prototype for the `1.0`
build form and configuration preview.

Open `index.html` locally. It demonstrates:

- grouped multi-choice;
- search, chips, select-all, clear, and invert;
- disabled options;
- configuration/public-model editing and generated Pipeline snippet;
- canonical value and environment export preview;
- reserved form presence markers and stable machine-value ordering;
- ready, empty, error, and configuration-error states;
- required/min-selection validation;
- responsive layout.

The prototype is not a production plugin bundle and is not used as a semantic
oracle. Normative behavior is defined by the UI interaction specification,
Canonical Value ADR, and parity tests.
