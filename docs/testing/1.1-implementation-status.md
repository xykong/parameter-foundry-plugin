# `1.1` Governed Provider Platform Implementation Status

- Review date: August 28, 2026
- Scope: current implementation and executable evidence
- Requirement source: [`requirements.yaml`](./requirements.yaml)

## Implemented Platform

- Global and Folder-scoped shared Provider registries with nearest-scope
  override, nested-Folder policy, and sibling isolation.
- Governed Connection Profiles binding authority, path/query allowlists,
  credential ID, headers, proxy/redirect policy, timeouts, and response limits.
- Static, Managed Config, and REST JSON/XML Providers.
- Safe JSONPath subset, secure XPath/XML parsing, declarative Transform Chain,
  bounded cache, in-flight coalescing, health, negative cache, fail-closed,
  empty, and last-known-good policies.
- Principal, Job, Provider, and controller budgets with validate/build reserved
  capacity and stable rate-limit errors.
- Editable single choice with shared server-side regex and length policy.
- Job DSL and JCasC public-model integration.
- Static migration clone/apply/rollback with compare-before-write, protected
  backup, audit record, and conflict refusal.
