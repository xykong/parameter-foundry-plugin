# `2.0` Complete Requirement Coverage Implementation Status

Date: August 28, 2026

## Implemented Platform

- `unifiedForm` typed field schema for string, text, integer, decimal, boolean,
  choice, multi-choice, date, time, read-only content, object, and array.
- Bounded nesting, field-count, length, regex, numeric-range, item-count,
  choice, disabled-value, duplicate, required, unknown-field, and type validation.
- Section, grid, tabs, collapsible, and conditional layout models.
- Canonical Map or JSON Pipeline output, complete JSON environment export, and
  governed per-field environment mappings.
- Secret fields cannot be included in complete-form environment export and are
  never mapped individually by the core value factory.
- CSP-safe built-in schema renderer with a working JSON no-JavaScript fallback.
- Renderer SPI with no raw HTML/JavaScript return path and an explicit security contract.
- Script Provider companion SPI with separate-plugin, permission, audit,
  bounded-output, and schema declarations.
- Administrator-only retirement dashboard with independent active Job,
  generated-source, queue, running-build, and historical-build reporting.
- Non-executing Active Choices and List Git Branches migration adapters that
  generate governed Provider/Form skeletons without copying scripts,
  repository URLs, or credentials.
- Stashed File migration boundary adapter that keeps file transport native
  instead of incorrectly converting uploads into choices.
- Native Core/File Parameters remain usable through Jenkins standard
  transports; the JSON Typed API reports them as unsupported instead of
  silently dropping uploaded content.

## Security Boundary

Core still does not execute arbitrary Groovy, JavaScript, HTML, or controller
file paths. Script execution and custom rendering can only be supplied by a
separately installed companion plugin. The core SPIs accept normalized options,
typed schema, reviewed static adjunct names, and declared security properties;
they do not accept Job-supplied class names, HTML, or executable source.

See
[`Companion Extension Boundary`](../architecture/companion-extension-boundary.md).
