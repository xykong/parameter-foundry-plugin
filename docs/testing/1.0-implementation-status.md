# `1.0` Static Choice Foundation Implementation Status

- Review date: August 28, 2026
- Scope: current implementation and executable evidence, not a GA release
  declaration
- Requirement source: [`requirements.yaml`](./requirements.yaml)

## Review Findings Closed

| Finding | Implemented correction | Evidence |
|---------|------------------------|----------|
| Webhook and remote-trigger profile missing | API-token-authenticated `buildWithParameters` fixture uses the normal decoder, validation service, and canonical build record | `ApiSecurityIntegrationTest.apiTokenRemoteAndWebhookStylePostsUseNormalValidationWithoutCrumbs` |
| Endpoint permission matrix incomplete | Anonymous, READ, BUILD, CONFIGURE, ADMINISTER, CSRF, request-shape, and request-size cases cover schema, resolve, validate, build, health, and import preview | `ApiSecurityIntegrationTest` |
| 10,000-option performance gates unmeasured | Reproducible 4-vCPU/8-GiB browser run records warm navigation, enhancement, search, selection, validation, payload, and DOM limits | `results/1.0-e2e-benchmark.json` |
| Accessibility and keyboard evidence incomplete | Automated labels, relationships, contrast, duplicate-ID checks plus chip, checkbox, group, details, focus, forced-colors, and 390px flows | `results/1.0-accessibility.json` |
| Theme evidence missing | Real Jenkins screenshots cover light, Dark Theme system mode, and browser forced-colors high contrast | `../ui-gallery/images/unified-parameters/` |
| Configuration preview too raw | Import preview now shows a bounded table, add/change/remove diff, Pipeline snippet, standard REST, Typed REST, output preview, and explicit apply state | `configuration-preview.png` and `config-import.js` |
| Migration existed only as an adapter API | Job action now shows classification, semantic decisions, target summary, generated Pipeline definition, and verification fixture without modifying the Job | `ExtendedChoiceMigrationUiTest` and `migration-preview.png` |
| No-JavaScript path was displayed but not end-to-end submittable | A CSRF-protected progressive fallback bridges native controls to canonical fields and schedules through `buildWithParameters` | `TechnicalPreviewIntegrationTest.noJavaScriptBuildFormContainsPresenceMetadata` and real-browser E2E |
