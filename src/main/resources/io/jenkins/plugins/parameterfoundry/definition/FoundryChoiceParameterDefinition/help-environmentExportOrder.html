Order used for the environment variable of a multiple-choice parameter. The canonical value is always the sorted, unordered set; this setting only decides how the set is written into the environment.
Canonical (sorted) order
The default. The environment variable lists the values in machine order, which keeps builds reproducible and comparable.
Submitted order
Keeps the order the caller submitted. Use it when a migrated Job's downstream scripts depend on the exact string the source control exported. Extended Choice compatibility list and checkbox forms submit in declared option order; explicit API inputs keep their caller order.
A missing value is treated as canonical, so definitions and build records created before this setting existed keep their behavior.
