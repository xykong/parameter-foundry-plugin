typed keeps Parameter Foundry values: a string for single selection and a list for multiple selection.

core-string is available for static multiple parameters using extended-choice compatibility with delimited environment export. It saves a Jenkins StringParameterValue with the exact legacy submission or default literal. Pipeline params, build API values and the environment therefore keep the original string, after source-compatible input evaluation. Form literals retain whitespace and empty tokens; CLI/repeated fields retain source trimming and filtering. Use it when legacy scripts consume the original string directly.
