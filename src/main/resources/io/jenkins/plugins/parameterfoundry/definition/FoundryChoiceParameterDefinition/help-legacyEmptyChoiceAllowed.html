Preserves empty tokens accepted by a static Extended Choice source whose comma-separated option configuration has leading or internal empty entries. Available only in standardApiInputMode: extended-choice. The migration adapter sets this field from the source configuration. A trailing comma alone does not enable it.

CLI and repeated standard requests retain accepted empty fields and their separator positions in the exported literal, for example ,alpha. The visible option list and canonical multiple values remain non-empty known choices, matching the source UI. Typed explicit values remain strict. Form JSON strings/arrays already preserve empty elements independently.

Omitting input still uses the source default; submitting an accepted empty field produces an existing empty value. Ordinary parameter modes cannot use this setting.
