What the Provider offers: the names of the connected agents, or the names of the labels assigned to nodes (including the built-in node's labels). This replaces an Active Choices script that read Jenkins.instance.nodes or Jenkins.instance.getSelfLabel(); the plugin reads the Jenkins model itself and never runs Job-provided code.

configured-nodes returns the built-in self label first, then configured node names in controller configuration order. With online-only disabled it includes offline nodes and nodes without a Computer. Names empty after Java String.trim() are filtered; every retained name keeps its original text, including Unicode whitespace and leading/trailing spaces. This mode can return an empty list; it does not execute a Job script. Existing nodes and labels modes retain sorted results.
