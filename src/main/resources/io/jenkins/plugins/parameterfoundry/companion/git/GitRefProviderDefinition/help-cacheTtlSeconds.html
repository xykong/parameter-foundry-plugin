How long a resolved option set is reused before the Provider is called again, in seconds. 0 disables caching, 86400 is the maximum.

The cache key includes the provider digest and the canonical dependency values, so a changed configuration or dependency resolves again.

With 0, the next request also retries immediately after a failed Git lookup. Request budgets and concurrent lookup sharing still apply. Positive values retain the generic failure cooldown. Declared failure policies and fallback options are unchanged.
