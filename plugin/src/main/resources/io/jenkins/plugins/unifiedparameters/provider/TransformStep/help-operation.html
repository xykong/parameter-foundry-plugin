What the step does:

  • filter keeps options whose selected field matches the pattern.
  • sort orders options by the selected field (descending reverses it).
  • distinct keeps the first option per field value.
  • limit keeps the first limit options.
  • map rewrites the selected field with a regex replacement.
  • group derives the selected field from a regex capture.
  • mark-disabled disables matching options and stores the reason.
