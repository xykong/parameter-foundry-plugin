A reviewed selectable value for this failure, followed by the raw trailing choices. Only the fixed tokens {status} and {uri} are replaced; no expression is evaluated. Using {uri} makes the configured request URL visible to parameter users, so use it only for public, non-secret URLs. Rows using {uri} interpolation require a query-free target. Administrator-declared literal values are shown as written and must be reviewed for disclosure and contain no secrets. Exception messages, response error bodies and authentication data are never interpolated.
