Mapped JSON/XML uses the configured root and field paths.

The two Active Choices single JSON modes interpret a reviewed JSON data-or-root response without executing Groovy. Use ordinary mode for Choice parameters and reactive mode for Cascade parameters. They preserve list/map order, source suffix metadata and their different null/blank captions and values. Root/field mapping and transforms do not apply.

Use these modes for reviewed PT_SINGLE_SELECT sources and a dropdown Foundry Choice parameter using standardApiInputMode: 'active-choices'. Ordinary API defaults are derived from the response separately from UI selection. Reactive definitions require an explicit literal API default; missing dependency requests can use reviewed fallback options. Disable caching when the source default is live.

Only JSON responses are accepted. The Connection Profile governs the endpoint, query parameters, credentials, deadline and response byte limit. The interpreter also bounds JSON depth to 64 and output to 10,000 distinct choices. Configure fallback options for the source exception fallback; do not use stale data as a substitute. Complete per-Job input and browser verification before migration.
