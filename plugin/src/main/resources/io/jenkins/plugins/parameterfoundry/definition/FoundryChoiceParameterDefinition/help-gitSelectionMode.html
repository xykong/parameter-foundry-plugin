Applies only to standardApiInputMode=list-git-branches. This preserves the source dropdown selection separately from the default used by API and CLI callers. default selects an exact stored-default match, then the first option containing that default, then the first option. top selects the first option. none leaves native selection: a one-row dropdown uses its first option; a multi-row list renderer or a searchable list explicitly configured with more than one visible row stays unselected. Searchable controls without an explicit row count retain their existing first-option behavior. Empty option sets have no selection. Changing this field does not change defaultMode or defaultValue.
