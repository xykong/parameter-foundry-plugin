How buildWithParameters decodes this parameter:

  • repeated expects one field per value.
  • json-array expects exactly one field holding a JSON array of strings.
  • delimited splits a single field on the delimiter below.
  • extended-choice preserves static Extended Choice multiple-selection transports: standard requests use repeated fields, trim values and ignore unavailable choices; CLI splits on commas; legacy form JSON accepts a delimiter-separated string or an array. Use submitted environment export order and duplicate deduplication; canonical values remain a set while repeated submitted values can remain in the exported string. Providers and tables cannot use this compatibility mode.

The Jenkins CLI accepts a JSON array in the other multiple-selection modes. Compatibility mode matches the source CLI's comma-separated input. The typed API always sends a JSON array.
