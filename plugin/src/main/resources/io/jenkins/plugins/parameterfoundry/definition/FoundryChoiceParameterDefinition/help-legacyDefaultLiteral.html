The exact default string exported by a migrated static Extended Choice parameter when CLI or standard API input is omitted. Available only with standardApiInputMode: extended-choice. Order, repeated values, whitespace and unavailable placeholder values are preserved in the environment export. This does not add unavailable values to the dropdown or permit them in explicit typed submissions.

Disabled options, required selection, selection counts and duplicate policy are checked against the supported canonical default. Conflicting constraints reject the default.

UI default selections remain configured separately using defaultValue (single) or defaultValues (multiple). A migrated single dropdown can show its first option while omitted API input still uses an unlisted literal or no ParameterValue. With this field blank, explicit UI defaults supply their comma-joined transport default; without those defaults, omission produces no ParameterValue, matching the source. Single first-option UI selection does not supply a transport default. An explicitly empty standard field or empty form submission remains an existing empty value.
