Order of the returned refs:

  • ascending / descending compare names as text.
  • none retains the default-sized Java HashSet iteration used by an unsorted List Git Branches ref category. This is neither alphabetical order nor Git advertisement order, and is not a stable ordering guarantee across runtimes. Verify actual values, category grouping and dropdown selection before migration.
  • smart-ascending / smart-descending compare numeric runs by value, so 1.9 sorts before 1.10. Use these to match the source plugin's *_SMART sort modes.

The order decides which ref the parameter uses when its default mode is first.
