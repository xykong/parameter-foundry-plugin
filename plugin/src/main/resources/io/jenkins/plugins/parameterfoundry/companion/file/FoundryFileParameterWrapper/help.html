Use this wrapper after allocating a Pipeline workspace, or configure it as a Freestyle build wrapper.

Base64 and stash modes bind the named environment variable to an agent-local temporary file and remove its directory when the block exits, including failure.

Workspace mode delivers to the definition's relative destination and retains Core filename environment semantics. It does not replace the variable with a temporary path or remove the destination. Freestyle already performs this delivery automatically.

Use allowNoFile: true for optional absence. A wrong-type value always fails. Delivery checks the current Job's file type and upload policy.
